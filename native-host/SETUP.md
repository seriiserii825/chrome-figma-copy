# Установка конвертации go-scss на новом компьютере

Что получится: `c t`, `c l`, `c s` в Figma копируют CSS уже приведённым
к виду проекта (замены из `projects/<проект>.txt`, em/rem, порядок свойств).
Отдельный процесс `go-scss` в терминале не нужен: Chrome запускает
`go-scss-host` сам, на каждое копирование.

Инструкция для Linux (проверено на Linux с Chrome/Chromium). `install.sh`
пишет манифест только в `~/.config/google-chrome` и `~/.config/chromium`.
Для macOS и Windows см. раздел «Другие ОС» внизу.

## Что нужно

- Go (1.22+; в `go.mod` указана новая версия, при ошибке сборки обнови Go).
- Chrome или Chromium.
- Доступ к двум репозиториям:
  - `go-scss` (клонируй в `~/Documents/go/go-scss`);
  - `chrome-figma-copy` (клонируй в `~/Documents/chrome-extensions/chrome-figma-copy`).
- Папка `~/Documents/go/go-scss/projects/` с файлами замен `<проект>.txt`.
  Путь зашит в хосте, поэтому должен совпадать. Если папки нет, создай её.
  Файлы замен перенеси вручную, например с другого ПК или через git,
  если они там коммитятся.

Токен Figma для этой функции не нужен. Он нужен только для кнопок popup,
которые читают REST API.

## Шаг 1. Собрать go-scss-host

```
cd ~/Documents/go/go-scss
go build -o ~/go/bin/go-scss-host ./cmd/go-scss-host
```

Проверка: `ls -l ~/go/bin/go-scss-host` — файл должен существовать и быть исполняемым.

Убедись, что `~/go/bin` есть в `PATH`, хотя для работы хоста это не обязательно:
`install.sh` пишет абсолютный путь.

## Шаг 2. Загрузить расширение

1. Открой `chrome://extensions/`.
2. Включи «Режим разработчика» (Developer mode).
3. «Загрузить распакованное» (Load unpacked) → выбери папку
   `~/Documents/chrome-extensions/chrome-figma-copy`.
4. Скопируй ID из карточки расширения: строка из 32 букв `a`–`p` под
   названием «Figma Copy — Page Order».

## Шаг 3. Зарегистрировать хост

```
cd ~/Documents/chrome-extensions/chrome-figma-copy
native-host/install.sh ВСТАВЬ_ID
```

Скрипт создаёт `~/.config/google-chrome/NativeMessagingHosts/com.gaba.go_scss.json`
(и то же для Chromium, если есть). В файле указан путь к `go-scss-host` и
ID, для которого разрешён доступ. Ожидаемый вывод: «Записано: …» и «Готово».

## Шаг 4. Перезагрузить расширение

На карточке расширения нажми перезагрузку. Если потом появится
«go-scss-host не отвечает», полностью перезапусти Chrome.

## Шаг 5. Настроить popup

1. Открой popup расширения.
2. Включи «Конвертировать при копировании».
3. В поле проекта введи имя папки проекта, например `ag-axel` для
   `projects/ag-axel.txt`. Без имени замены не применяются, остальная
   конвертация работает.
4. При необходимости включи «px → rem».

Настройки сохраняются сразу.

## Шаг 6. Проверить

1. Открой файл в Figma с `?m=dev` в адресе.
2. Выдели текстовый слой, открой вкладку Code.
3. Нажми `c`, затем `t`.
4. Вставь буфер в текстовое поле. Значения должны быть уже сконвертированы.

Если вставилось исходное значение, или появился тост «go-scss: …»,
см. «Проблемы» ниже.

## Проблемы

| Симптом | Причина и что делать |
|---|---|
| Тост «go-scss-host не отвечает» | Не записан манифест или Chrome не перезапускался. Повтори шаг 3, перезапусти Chrome. |
| Тост «variables file … created empty … fill it» | Файла замен для проекта нет, создан пустой. Заполни `projects/<проект>.txt` или очисти поле проекта в popup. |
| Тост «invalid project name» | В поле проекта указан путь, а не имя. Укажи только имя папки. |
| Копируется без изменений | Не включён переключатель, либо расширение загружено из другой папки (другой ID). Проверь popup и повтори шаг 3 с актуальным ID. |
| Ошибка сразу после переноса расширения | ID изменился (расширение загружено из другой папки). Повтори шаг 3 с новым ID. |
| `go-scss-host` не найден | Не собран или собран не в `~/go/bin`. Повтори шаг 1. |

Проверить хост вручную (без Chrome): запусти `~/go/bin/go-scss-host`
с сообщением в протоколе Chrome, либо запусти тесты:
`cd ~/Documents/go/go-scss && go test ./cmd/...`.

## Другие ОС

- **macOS.** Папка манифеста: `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/`.
  Путь к `go-scss-host` — `~/go/bin/go-scss-host`. `install.sh` использует
  пути Linux, поэтому скопируй JSON вручную, подставив свой ID и путь.
- **Windows.** Нужен ключ реестра
  `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.gaba.go_scss`
  со значением по умолчанию — путь к JSON-манифесту. Сам манифест
  содержит путь к `go-scss-host.exe`. Также нужно собрать `.exe`
  (`go build -o go-scss-host.exe ./cmd/go-scss-host`). Скрипт `install.sh`
  здесь не работает.

## Важно

- Если поменяешь папку расширения, его ID изменится. Повтори шаг 3.
- Хост читает замены из `~/Documents/go/go-scss/projects/` при каждом
  копировании, поэтому правки в файлах видны сразу без перезапуска.
- Поле проекта в popup — это имя файла без `.txt`.

## Пересборка и обновления

Что делать после изменений:

| Что поменялось | Что сделать |
|---|---|
| `popup.*`, `content.js`, `background.js`, `figma-clipboard-main.js`, `manifest.json` (без новых разрешений) | Нажать перезагрузку расширения в `chrome://extensions/` |
| `manifest.json` с новыми `permissions` | Перезагрузить расширение, Chrome может попросить подтвердить разрешения |
| `cmd/go-scss-host/*.go` или `scss/*.go` (логика конвертации) | Пересобрать хост (команда ниже). Регистрация не меняется, Chrome запускает бинарник заново |
| Файл замен `projects/<проект>.txt` | Ничего, читается при каждом копировании |
| Новый проект | Создать `projects/<имя>.txt`, ввести имя в popup. Пересборка не нужна |
| Расширение перенесено или загружено из другой папки (сменился ID) | Повторить `native-host/install.sh <новый ID>` |
| Переехала папка `go-scss` или сменился путь к `~/go/bin/go-scss-host` | Пересобрать хост и повторить `install.sh <ID>` |
| Ошибка «go-scss-host не отвечает» после всего этого | Перезапустить Chrome |

Пересборка хоста:

```
cd ~/Documents/go/go-scss
go test ./cmd/...
go build -o ~/go/bin/go-scss-host ./cmd/go-scss-host
```

Регистрация хоста:

```
cd ~/Documents/chrome-extensions/chrome-figma-copy
native-host/install.sh ID_РАСШИРЕНИЯ
```

Проверка без Chrome: `ls -l ~/go/bin/go-scss-host` (файл исполняемый, дата
обновилась после сборки).

## Что нельзя потерять

- **Код хоста не в git.** `cmd/go-scss-host/` в репозитории `go-scss` пока
  не закоммичен (статус `??`). На другом ПК `git clone` его не даст. Перед
  переносом закоммить и запушь `cmd/go-scss-host/`.
- **Изменения расширения не закоммичены.** Файлы `figma-clipboard-main.js`,
  `native-host/`, а также правки `background.js`, `content.js`,
  `manifest.json`, `popup.*`, `README.md` есть только локально.
- **Файлы замен** в `go-scss/projects/` тоже должны попасть на новый ПК
  отдельно (через git или копированием). Без них замен не будет.
- **ID расширения** не сохраняется. Его надо заново узнать на каждом ПК
  и передать `install.sh`.
- **Токен Figma** в этой функции не нужен, в git его не клади.
- **`go-scss/projects/ag-axel.txt`** на текущем ПК имеет незакоммиченное
  изменение, которое не относится к этой функции.
